# Вариант 3 — паспорт информационного ресурса

Информационный ресурс: Сайт Счетной палаты Российской Федерации.
Входящие в ресурс базы: База данных "Интернет-сайт Счетной палаты Российской Федерации".

- Периодичность обновления информации: постоянно
- Срок хранения информации: не ограничен
- Серверная ОС: MS Windows Server 2008; Linux; Microsoft Windows 2003 Server; MS Windows Server 2012
- Клиентские ОС: MS Windows 2000/XP/7/8
- СУБД: Microsoft Access; Microsoft SQL Server; MySQL; Oracle
- ПО для управления сетевыми ресурсами: Internet Information Services
- Прикладное ПО (выборка, важное для стенда): MS Office, Adobe Acrobat, САДЭД "Дело", "ЭЦП и шифрование", КриптоПро, SecretNet, VmWare Workstation 7
- Свободное ПО: Linux Red Hat, Fedora Core, Mandriva Server, Postfix, Firefox, ClamAV, Thunderbird, Open Office
- Аппаратное обеспечение: Intel x86 (64bit)
- Форматы данных для структурированного представления информации в сети: XML; HTML
- Форматы хранения: XLS; BMP; HTML; RAR; ZIP; AVI; DOC; DOCX; TXT; RTF; GIF; JPEG; PCX; PNG; PSD; TIFF; CDR; PDF; MOV; MIDI; WAV; mdb; MDF; LDF; dbf; XLSX
- Количество мест, подключенных к системе: 1232
- Общее количество сертификатов ключа цифровой подписи: 500
- Тип криптозащиты информации в системе: программно-аппаратный
- Информация ограниченного доступа в ФГИС: персональные данные; служебная тайна

## Решения группы по реализации стенда (из чата)
- ОС на всех хостах: Debian
- Межсетевой экран: nftables
- Защищённый канал: WireGuard
- СУБД: PostgreSQL (без отечественного/кастомного)
- Secret Net (Windows, платный) заменяем открытыми аналогами; в отчёте это указать
