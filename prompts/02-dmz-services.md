# Этап 02 — сервисы ДМЗ и БД

## Цель
Заменить заглушки на реальные сервисы ресурса «Интернет-сайт Счётной палаты РФ»: web (Apache + PHP), FTP (vsftpd), БД (PostgreSQL). Защита информации здесь: сегментация, ограничение доступа к БД, HTTPS.

## Что сделать
1. **db** (intra .10): PostgreSQL, база `site` с таблицами `news` и `documents` (несколько учебных записей), учётка `webapp` с минимальными правами (только нужные таблицы), `pg_hba.conf` пускает `webapp` только с адреса web (192.168.100.10). Слушает не на всех интерфейсах без причины.
2. **web** (dmz .10): Apache + PHP. Учебный сайт-заглушка «Интернет-сайт Счётной палаты РФ»: главная, список новостей из БД, страница документов, форма поиска `/search.php`. Страница поиска намеренно отражает ввод без экранирования, это нужно для демонстрации IDS (XSS) на этапе 03. Пометь это в коде комментарием «учебная уязвимость». HTTPS на самоподписанном сертификате (в отчёте так и пишем: ГОСТ-TLS недоступен, используется обычный TLS). HTTP → редирект на HTTPS или оба порта открыты, реши сам и запиши.
3. **ftp** (dmz .11): vsftpd, локальный пользователь для бэкапов с chroot, анонимный доступ выключен, фиксированный диапазон пассивных портов (согласуй с правилами gw-dmz). Скрипт `backup.sh`: `pg_dump` из db → загрузка на ftp. Запуск вручную с db или с arm1 (когда он будет).
4. Обнови правила МЭ из этапа 01, если нужно (диапазон пассивных портов и т. п.), и запиши, что поменял.

## Обязательные проверки (каждая со скрином)
- `client` → `https://198.51.100.1/` отдаёт сайт, страница с новостями показывает данные из БД. Веб-страницу сними через `shot-web.sh` (PNG браузера), плюс `curl -k -I`.
- `attacker` → 198.51.100.1:21 и :5432 недоступны. ICMP до внутренних адресов не проходит.
- web → БД: запрос под `webapp` проходит; `webapp` с другого хоста (например, ftp или arm1/attacker) отклоняется `pg_hba`; `webapp` не может читать чужие таблицы (если такие есть) или менять схему.
- Проверка бэкапа: `backup.sh` отрабатывает, файл виден на ftp, `ftp` с анонимным доступом отклоняется. FTP из ext недоступен (МЭ), из intra доступен.
- `nft list ruleset` на gw-dmz после проверок (счётчики показывают срабатывание).
- Версии установленных пакетов (`apache2 -v`, `psql --version`, `vsftpd -v`) для отчёта.
